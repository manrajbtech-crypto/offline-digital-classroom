Offline EduHub is a zero-data, edge educational platform designed for internet-deprived regions, refugee camps, and disaster zones. Built on a native, zero-dependency Node.js architecture, it transforms any standard PC into a local Wi-Fi learning server operating with zero cellular or broadband data usage.Through an intuitive dashboard, teachers can dynamically upload PDF textbooks, publish interactive quizzes, and monitor live gradebook analytics. Students access content seamlessly on mobile devices via a responsive web app. If Wi-Fi drops, responses buffer locally in browser storage and automatically sync upon reconnection—delivering seamless, low-power educational continuity for off-grid communities.
